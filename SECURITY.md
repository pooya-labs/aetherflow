# Security

AetherFlow is an early-stage project and is not recommended for production workloads.

Please report security concerns privately to the repository owner rather than posting sensitive details in a public issue. Include the affected revision, impact, and a safe reproduction when possible. Do not include credentials, personal data, or production secrets.

No production security audit has been performed. Authentication, authorization, tenant isolation, and plugin sandboxing are roadmap items and are not yet available protections. Do not run untrusted workloads against sensitive infrastructure.
